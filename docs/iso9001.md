# ISO 9001 · Matriz de trazabilidad para StockTrack

## Alcance (leer primero)

ISO 9001:2015 certifica el **sistema de gestión de calidad de una organización**, no un programa de software. Por lo tanto,
StockTrack **no puede «estar certificado» en ISO 9001**: lo que sí hace es dar *soporte y evidencia* a los controles de calidad del
proceso de inventario de la tienda, y este documento muestra cómo. La conformidad real depende además de los procedimientos
de la tienda (quién cuenta, cuándo, cómo se corrige un error) y de una auditoría.

## Cómo StockTrack apoya cada requisito

| Cláusula ISO 9001:2015 | Qué pide, en términos del inventario | Cómo lo apoya StockTrack | Evidencia |
|---|---|---|---|
| 4.4 Sistema y procesos | Proceso definido con entradas y salidas | Flujo único: alta de producto → movimientos → alertas → reportes | README, `docs/kanban.md` |
| 5.3 Roles y responsabilidades | Responsabilidades asignadas y diferenciadas | 3 roles con permisos explícitos | RN-01.1 |
| 6.1 Riesgos y oportunidades | Anticipar pérdidas y faltantes | Alertas de escasez (umbral por producto), stock nunca negativo, tope de capacidad | PA-02.x, PA-03.2, RN-02.1 |
| 7.1.5 Recursos de seguimiento y medición | Datos de existencias confiables | Movimientos con stock antes/después; reservas validadas por el administrador | `tests/test_models.py` |
| 7.5 Información documentada | Registros controlados y protegidos | Bitácora de auditoría (usuario, fecha, IP, cambio); no se borran movimientos | `models/audit.py` |
| 8.5.2 Identificación y trazabilidad | Rastrear cada unidad movida | Cada movimiento guarda producto, usuario, tipo, cantidad, stock antes/después y referencia | PA-03.3 |
| 8.5.4 Preservación | Evitar deterioro/pérdida | Productos se archivan (no se eliminan) conservando el historial | RN-02.1 |
| 8.6 / 8.7 Salidas no conformes | Controlar errores antes de que se propaguen | Validaciones; rechazo de salidas sin stock; atención de alertas | PA-03.2 |
| 9.1 Seguimiento y análisis | Indicadores para decidir | Panel (valor, escasez, agotados) y reportes PDF/Excel | PA-01.x |
| 9.2 Auditoría interna | Evidencia revisable | Bitácora consultable por administrador; reportes foliados con SHA-256 | `views/audit.py` |
| 10.2 No conformidad y acción correctiva | Registrar y corregir | Rechazo de reservas con motivo; alertas (abierta → atendida → resuelta) | PA-02.4 |

## Lo que debe aportar la organización

Procedimiento escrito de conteos cíclicos y correcciones (quién autoriza), política de respaldos, revisión periódica de usuarios
y permisos, y la revisión por la dirección (9.3). Sin eso no hay conformidad aunque el software registre todo.
